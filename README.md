This BinaryTree code parses input text (delimited by spaces) and placed each word into the tree.
The code is structured to be modular, so that any kind of Item could used, assuming that Item has a value
assodicated with it, upon which the sorting is based.
I noticed that several of the words appeard in the example text both capitalized and lower case.  In the
value calculation I simply subtracted 1 for each capital letter in the word, so that it would appear adjacent
to the lower case version - see version 1.1.
Later I wanted to see how much benetid could be obtained by balancing the tree - see version 1.6 and the Excel
computation of the difference in search depth that the balance achieved.

All just for fun with my grandson.
I did a similar exercise in Pascal as an exercise for an algorithm class I was teaching at a JC years ago.
